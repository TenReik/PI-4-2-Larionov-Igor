## Статья 3. Privacy-preserving techniques in recommender systems: a systematic review  
*Источник: Data Technologies and Applications (Emerald), 2023*  
(https://www.emerald.com/dta/article-abstract/57/1/32/26217)

### Цель
Систематизация методов защиты приватности в рекомендательных системах, анализ их эффективности и формулировка направлений будущих исследований для безопасной обработки персональных данных пользователей.

### Задачи
*   Провести систематический обзор литературы (PRISMA) по теме privacy-preserving RS.
*   Классифицировать существующие техники: дифференциальная приватность, федеративное обучение, гомоморфное шифрование, анонимизация.
*   Оценить компромисс между качеством рекомендаций и уровнем защиты данных.
*   Сформулировать исследовательскую повестку для разработки безопасных рекомендательных систем.

### Эксперимент
Методология: отбор 41 релевантной статьи из баз SCOPUS, Web of Science, Google Scholar. Качественный синтез: анализ целей, методов, метрик и ограничений каждого исследования. Сравнение подходов по критериям: уровень защиты, влияние на точность, вычислительная сложность, применимость в реальных системах.

### Результаты
*   Выделено 5 основных категорий методов защиты: (1) анонимизация данных, (2) дифференциальная приватность, (3) федеративное обучение, (4) криптографические методы, (5) гибридные подходы.
*   Наиболее сбалансированными по соотношению «точность/защита» признаны методы дифференциальной приватности с адаптивным шумом и федеративное обучение с безопасной агрегацией.
*   Установлено, что внедрение privacy-техник снижает точность рекомендаций в среднем на 3–8%, что считается приемлемым компромиссом для систем, обрабатывающих ПДн.

### Значимость
Для дипломного проекта это исследование критически важно в контексте раздела «Безопасность (ФСТЭК №21, №17)». Результаты обосновывают выбор организационно-технических мер: псевдонимизация идентификаторов, разделение контуров обработки, применение дифференциальной приватности при сборе аналитики. Это позволяет проектировать сервис, соответствующий регуляторным требованиям без существенной потери качества рекомендаций.
