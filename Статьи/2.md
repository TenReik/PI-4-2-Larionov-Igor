## Статья 2. Context-Aware Music Recommendation Algorithm Combining Classification and Collaborative Filtering  
*Источник: Scalable Computing: Practice and Experience (SCPE), 2024*  
(https://www.scpe.org/index.php/scpe/article/view/2792)

### Цель
Повышение точности персонализированных музыкальных рекомендаций за счёт интеграции классификации музыкальных жанров по контексту и улучшенной коллаборативной фильтрации с учётом ситуационной информации пользователя.

### Задачи
*   Провести анализ схожести пользовательских ситуаций (контекстов) на основе метаданных и поведения.
*   Получить предварительный список рекомендаций с помощью модифицированного алгоритма коллаборативной фильтрации.
*   Применить методы машинного обучения для классификации музыкальных треков по типам сценариев (работа, спорт, отдых и т.д.).
*   Объединить результаты коллаборативной фильтрации и классификации для формирования финальной персонализированной подборки.

### Эксперимент
Алгоритм тестировался на наборе данных с аннотированными пользовательскими сессиями. Контекст определялся по меткам: время суток, тип активности, текстовое описание настроения. Использовались метрики точности (Precision@K, Recall@K) и пользовательская оценка релевантности (опрос после сессии). Сравнение проводилось с классической CF и контентной фильтрацией.

### Результаты
*   Предложенный гибридный алгоритм показал прирост точности рекомендаций на **18–24%** по сравнению с моно-методами.
*   Классификация по контексту позволила снизить количество «неуместных» рекомендаций (например, энергичная музыка в сценарии «сон») на **31%**.
*   Пользователи отметили более высокую удовлетворённость (CSAT +22%) при использовании контекстно-зависимых подборок.

### Значимость
Исследование напрямую поддерживает ключевую фичу дипломного проекта — подбор музыки по цели и настроению. Результаты подтверждают целесообразность внедрения модуля контекстной классификации в Recommendation Service и обосновывают использование текстовых запросов («спокойное, как Lo-Fi») как входных признаков для модели.
